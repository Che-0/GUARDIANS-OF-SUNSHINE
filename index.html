📖 MANUAL DE BMO ZONA 1: EXTERIOR
🎮 Botones de BMO / Teclado
  • ✚ CRUCETA o ← / → : Moverse
  • 🔴 ROJO GRANDE (B) o ESPACIO : Saltar
  • 🔺 TRIÁNGULO AZUL o Z : Atacar
  • 🟢 CÍRCULO VERDE o X : Lanzar Bomba Solar
  • ➖ PÍLDORAS INFERIORES : START (Iniciar) y FINN/JAKE (Tecla C)
⚔️ Héroes Jugables (Botón FINN/JAKE o C)
👦 FINN

Mayor velocidad de movimiento y salto más alto para esquivar fosos.

🐶 JAKE

Puño elástico con el doble de alcance horizontal y mayor daño.

💣 COMBO SECRETO (Bomba Solar)

El jefe final Sleepy Sam es inmune a golpes normales. Presiona esta secuencia en la cruceta y termina con el botón verde (X):

↑ ARRIBA ➔ ↓ ABAJO ➔ ← IZQ ➔ → DER ➔ 🟢 VERDE (X)
👾 Los 3 Guardianes (Jefes)
  • 🐝 1. Bouncy Bee: Vuela en onda senoidal, dispara aguijones y embiste a ras de suelo.
  • 🐰 2. Honey Bunny: Sus saltos pesados derriban estalactitas del techo y dispara rayos láser.
  • 🐸 3. Sleepy Sam: Escupe fuego detrás de un foso de ácido. ¡Usa el Combo Secreto para vencerlo!
